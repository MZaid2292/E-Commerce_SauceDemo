# SauceDemo E-Commerce - Test Plan

## 1. Objective
To verify the main e-commerce workflows of SauceDemo
and automate them using Python, Playwright, and Pytest.

## 2. Application Under Test
https://www.saucedemo.com/

## 3. Scope of Testing
- Login and authentication
- Product listing
- Product sorting
- Add and remove products from cart
- Checkout form validation
- Order completion
- Logout

## 4. Testing Approach
- Manual testing
- Positive and negative testing
- UI automation using Playwright
- Assertions using Pytest
- Failure investigation using screenshots and traces

## 5. Test Environment
- Operating System: Windows
- Language: Python
- Automation Tool: Playwright
- Test Framework: Pytest
- Browser: Chromium
- IDE: Visual Studio Code

## 6. Entry Criteria
- Application is accessible.
- Python and required packages are installed.
- Browser automation environment is working.

## 7. Exit Criteria
- Planned test cases have been executed.
- Test results have been recorded.
- Failures have been investigated and documented.

## 8. Deliverables
- Test plan and test cases
- Automated test scripts
- Test execution reports
- Failure screenshots and traces
- GitHub repository and README
